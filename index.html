How borrowing works

  1. 1
    Submit

    Choose equipment, quantity, and return date. Your request starts as Pending.

  2. 2
    Admin review

    An administrator approves or rejects the request.

  3. 3
    Pick up

    Laboratory staff release the equipment to you once approved.

  4. 4
    Return

    Return the item on or before the due date. Late returns are flagged as Overdue.

You can cancel a request while it is still pending.
